# 산정특례 기준 찾아보기

Public reference tool, deployed with GitHub Pages. No patient data, accounts, or server-side writes.

- 1,973 search entries, 50 editions, 594 source documents.
- Dedicated rare-disease Annex 4 table: 30 editions; original text, merged cells and bounded conditions retained.
- 617 original files are preserved byte-for-byte in 7 ZIP bundles. Individual downloads extract the selected file in the browser and verify SHA-256 before saving. ZIPs remain directly downloadable.
- Earlier three-column 희귀난치 editions remain searchable in the original/history views. Their embedded KCD codes are not inferred as separate columns.
- Reference only. Confirm the official criteria effective on the date of care.

Validated: exact source-cell text and spans, source SHA-256, row-specific search, condition isolation, 617 ZIP extractions, regression of existing search/history/download metadata.
