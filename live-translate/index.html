API 키나 유료 번역 서비스 신청은 필요하지 않습니다. 인터넷 연결은 필요합니다.

Chrome용 · v1.0.0
01

연결 프로그램 설치

다운로드한 ZIP 파일을 압축 해제하세요. Chrome 주소창에 chrome://extensions를 입력하고, 오른쪽 위 개발자 모드를 켭니다.

압축해제된 확장 프로그램을 로드합니다에서 Lecture-Note-Bridge 폴더를 선택하세요. 이 페이지를 새로고침하면 연결 상태가 표시됩니다.

02

강의 기록 시작

강의 이름과 언어를 정하고 기록 시작을 누르세요. 새로 열린 Google 번역 탭에서 마이크 버튼을 눌러 음성 입력을 시작합니다.

두 창을 나란히 띄우세요. Google의 마이크가 멈추면 다시 눌러야 합니다. 입력 언어는 자동 감지가 아닌 강의 언어로 선택하세요.

03

기록 확인 · 저장

기록은 최신순, 문서는 시간순입니다. 종료 · 저장 후 바로 다음 강의를 시작할 수 있습니다. Google 번역의 마이크도 직접 꺼주세요.

Word는 .docx 파일, PDF는 인쇄 창에서 PDF로 저장을 선택합니다. 보관함에서 이름 변경·휴지통 이동·백업이 가능합니다.

사용 전 알아두세요
  • 자동 연결은 이 확장 프로그램을 설치한 Chrome에서 지원합니다. Safari에서는 저장된 기록 보기·직접 입력·문서 저장을 사용할 수 있습니다. 브라우저끼리 기록이 자동 공유되지는 않습니다.
  • Google은 음성 인식의 최종 확정 신호를 제공하지 않습니다. 화면이 2.2초 이상 바뀌지 않으면 안정된 기록으로 표시하며 이후 수정될 수 있습니다.
  • 원문과 번역의 문장 수가 같으면 문장별로, 다르면 정확한 대응을 임의로 만들지 않고 한 구간으로 저장합니다. 문장별 시간은 처음 관찰한 시각입니다. 한 구간으로 합쳐질 때는 구간의 첫 관찰 시각을 사용합니다.
  • Google 입력창을 비우면 새 구간이 됩니다. 5,000자 제한에 가까워지면 기존 내용이 저장된 것을 확인하고 Google에서 원문 삭제 후 음성 입력을 다시 시작하세요.
  • Google 화면 구조가 바뀌면 연결이 중단될 수 있습니다. 이 경우 직접 입력으로 원문과 번역을 보존할 수 있습니다.
  • 음성 파일 자체는 저장하지 않습니다. Google로 보낸 음성·텍스트는 Google 서비스에서 처리되며, Lecture Note 기록은 현재 브라우저에만 저장됩니다. 공개 GitHub 저장소에는 강의 내용을 전송하지 않습니다.
  • 페이지를 닫거나 연결이 끊기면 최대 15초 안에 수집을 중단합니다. 시크릿 모드나 사이트 데이터 삭제로 기록이 사라질 수 있으니 중요한 강의는 백업하세요.
